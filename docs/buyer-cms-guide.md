# 購入者向け microCMS 更新手順

日常の更新はmicroCMS管理画面だけで完了します。サイトのコードやAPIキーを触る必要はありません。

## コース料理を更新する

1. 左メニューの「コース料理」を開きます。
2. 既存料理を編集するか「追加」を選びます。
3. 章、料理名、説明、産地、写真、補足情報を入力します。
4. `sortOrder` に表示順を入力します。先頭は10、次は20のようにすると、後から間へ15を追加できます。
5. プレビューを確認し、「公開」を押します。

写真には料理が伝わるaltテキストも設定してください。被写体を短く具体的に書き、画像内に文字がある場合はその内容も含めます。未公開の料理はサイトに表示されません。全件を公開停止するとローカルの既定コースへ戻るため、常に1件以上を公開してください。

## 価格・営業時間・予約情報・店舗情報を更新する

1. 左メニューの「店舗設定」を開きます。
2. 変更したい項目だけを編集します。
3. 価格はカンマや「円」を付けず数値で入力します（例: `33000`）。表示補足は「価格の後ろの注記」に入力します。
4. 予約時間は `18:00` の形式で1行に1つ入力します。
5. 営業時間・定休日の表示文と、予約フォームの定休日設定の両方に矛盾がないか確認します。
6. 「公開」を押します。

価格、サービス料、予約時間、受付人数、予約受付月数は予約フォームの計算・入力チェックにも使われます。変更時は公開後に実際の予約フォームを最後の確認画面まで進め、金額と選択肢を確認してください。

## お知らせを追加する

1. 左メニューの「お知らせ」を開き、「追加」を選びます。
2. 日付、本文、`sortOrder` を入力します。
3. 「公開」を押します。

表示順は `sortOrder` の小さい順です。終了したお知らせは「公開停止」にするとサイトから外れます。

## 公開後の確認

通常は公開後数秒で反映されます。反映されない場合は次を順に試してください。

1. 対象が「下書き」ではなく「公開中」になっているか確認する。
2. ブラウザを再読み込みする。
3. 5分待って再読み込みする（Webhook失敗時の自動再取得待ち）。
4. それでも反映されない場合は、管理者へ「API名」「コンテンツ名」「公開した時刻」を連絡する。

通信障害時はサイトが真っ白にならず、納品時の既定情報が表示されます。障害中に予約条件を変更した場合は、復旧後にサイト表示と予約フォームの条件が一致しているか確認してください。
